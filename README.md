# Little Lemon Mobile App - Capstone Project

A complete React Native application built with Expo, React Navigation, AsyncStorage, and SQLite.

## Features
- **Onboarding Screen**: Validation for name and email with dynamic Next button.
- **Home Screen**: Header, Hero section, Category filters, and offline-first Food menu.
- **Profile Screen**: Edit & persist personal details and notification preferences. Complete reset on logout.
- **Wireframe**: Included as `wireframe.jpg`.
